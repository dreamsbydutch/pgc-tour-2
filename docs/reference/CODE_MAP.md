## Architecture and delivery workflows

| Concern                              | Primary sources                                                         | Guard/proof                                        | Skill                                                          |
| ------------------------------------ | ----------------------------------------------------------------------- | -------------------------------------------------- | -------------------------------------------------------------- |
| Frontend placement/aliases           | `AGENTS.md`, `eslint.config.js`, `tsconfig.json`, `src/` barrels        | ESLint, typecheck, focused render/hook tests       | `$pgc-frontend-flows`                                          |
| Public DTO privacy and bounded reads | `utils/auth.ts`, `utils/publicDtos.ts`, screen queries                  | `npm run convex:io-check`, hardening/payload tests | `$pgc-convex-boundaries`                                       |
| Schema/index change                  | `convex/schema.ts`, affected function/tests, generated model            | typecheck, Convex tests, I/O guard, generated diff | `$pgc-convex-boundaries`; repair skill if stored data changes  |
| Migration/backfill/cleanup           | `functions/migrations.ts`, `readModels.ts`, standings/sync/ESPN modules | dev dry run, cursor/idempotency/auth/audit tests   | `$pgc-data-repairs`                                            |
| CI/build/bundle                      | `package.json`, `.github/workflows/`, `vite.config.ts`, `scripts/`      | focused commands or `npm run check`                | Follow `AGENTS.md`; delivery skill does not own implementation |
| Completed-goal preview PR delivery   | Git state/history plus GitHub deployment/check/status metadata          | scoped commits, final gate, attributable preview   | `$create-pgc-preview-pr` only when explicitly requested        |
| Existing pull-request maintenance    | Existing GitHub PR, current head SHA, checks, deployments, and reviews  | current-SHA status, scoped requested follow-ups    | `$maintain-pgc-pr`; never initial PR creation                  |

## Trace templates

For a screen bug:

```text
route/search -> facilitator/display -> hook view model -> public Convex DTO
  -> table/index -> current/corrected state -> focused render + backend test
```

For a league result bug:

```text
provider/canonical input -> validated storage -> score/result -> award
  -> standings contribution/row -> playoff/badge/timeline/message -> UI
```

For an operator failure:

```text
admin/cron trigger -> auth/self-gate -> syncRuns or domain lease
  -> external/internal work -> persisted marker -> retry/repair path -> audit
```
